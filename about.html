About This
Project

An AI-inspired academic feedback system built for educational decision-making

(01) Our Mission

To transform the way educational institutions collect, analyze, and act upon student feedback — making education more responsive, data-driven, and student-centered.

The Problem

Educational institutions collect large volumes of student feedback, but analyzing it manually is time-consuming and error-prone. Important insights can be missed, and patterns may go unnoticed.

Our Solution

→ Collects feedback through easy-to-use web forms
→ Classifies sentiment using rule-based logic + HuggingFace ML
→ Stores all data persistently in MySQL
→ Identifies trends using real-time Chart.js charts
→ Presents actionable insights through interactive dashboards

(02) Process

How It
Works

1

Collection

Students submit structured feedback through web forms including course, instructor, ratings, and comments.

2

Analysis

Rule-based engine with HuggingFace ML fallback classifies sentiment using keyword dictionaries and rating weighting.

3

Storage

Feedback, sentiment, confidence score, and metadata are stored in MySQL via a Node.js/Express REST API.

4

Visualization

Trend lines, doughnut charts, bar graphs, and insight cards show student satisfaction at a glance.

(03) Tech Stack

Built With

Node.js Express.js MySQL Tailwind CSS Chart.js HuggingFace API Vanilla JS REST API
